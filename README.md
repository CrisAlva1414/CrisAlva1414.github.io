# IntegraLab

IntegraLab es una aplicación web moderna para la gestión integral de condominios y propiedades residenciales, diseñada para simplificar la administración y mejorar la experiencia de los residentes.

## 🌟 Características

- 📊 Panel de control intuitivo con estadísticas en tiempo real
- 🚪 Control de accesos y registro de visitantes
- 📦 Gestión de paquetería y correspondencia
- 👥 Administración de residentes y propietarios
- 🎥 Monitoreo de cámaras de seguridad
- 💰 Control financiero y pagos de mantenimiento
- 📱 Interfaz responsive para acceso desde cualquier dispositivo

## 🛠️ Tecnologías

- **Frontend:**
  - React 18
  - TypeScript
  - Tailwind CSS
  - Radix UI
  - Shadcn/ui Components
  - React Router DOM
  - React Query

- **Herramientas de desarrollo:**
  - Vite
  - ESLint
  - PostCSS
  - SWC

## 🚀 Inicio rápido

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/IntegraLab.git
```

2. Instala las dependencias:
```bash
cd IntegraLab
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
```

4. Abre http://localhost:8080 en tu navegador

## 📦 Construcción

Para construir el proyecto para producción:

```bash
npm run build
```
